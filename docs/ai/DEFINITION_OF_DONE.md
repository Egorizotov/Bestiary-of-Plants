# Definition of Done для AI-изменений

Задача считается готовой только в той мере, в которой выполнены применимые критерии ниже.

## Для любой задачи

- [ ] Результат соответствует запросу и связанным требованиям.
- [ ] Изменения ограничены областью задачи; незатронутый код не переписан.
- [ ] Нет секретов, случайных файлов, фиктивных источников и вводящих в заблуждение заявлений.
- [ ] Документация обновлена, если изменилось поведение, запуск, контракт или архитектура.
- [ ] Выполнены релевантные проверки либо в отчёте явно описано, почему они не выполнялись.
- [ ] В итоговом ответе перечислены изменённые файлы и фактические результаты проверок.

## Для интерфейса

- [ ] Сохранены стиль и структура существующей страницы, если редизайн не запрошен.
- [ ] Поисковое поле и кнопки имеют осмысленное поведение.
- [ ] Учтены пустой ввод, загрузка, успешный результат, отсутствие результатов и ошибка — в рамках задачи.
- [ ] Основные элементы доступны с клавиатуры и имеют понятные подписи.
- [ ] Страница не ломается на узком экране.
- [ ] Mock-данные не выданы за реальные результаты backend.

## Для корпуса и BM25

- [ ] У записей есть стабильные идентификаторы и источник происхождения.
- [ ] Повторяющиеся/пустые/повреждённые записи обнаруживаются или документированы.
- [ ] Изменения проверены на фиксированных запросах benchmark.
- [ ] В отчёте указывается, что измерялось; метрики не выдуманы.

## Для API и интеграции

- [ ] Формат входа, успеха и ошибок согласован с потребителями.
- [ ] Таймауты и ожидаемые ошибки обрабатываются в стиле проекта.
- [ ] Изменение контракта отражено в спецификации и тестах.
- [ ] Секреты передаются конфигурацией, а не хранятся в исходниках.

## Для LLM/RAG

- [ ] Контекст, передаваемый модели, формируется из результатов retrieval.
- [ ] Для ответа доступны метаданные источников.
- [ ] Нет релевантного контекста — это явное состояние, а не повод выдумывать ответ.
- [ ] Содержимое retrieval считается данными, а не инструкциями агенту.
- [ ] Есть тесты на нерелевантный запрос и на конфликт/недостаточность контекста, если RAG реализован.
- [ ] Не заявляется точность, которая не подтверждена тестированием.
