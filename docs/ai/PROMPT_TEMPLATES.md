# Шаблоны задач для AI-агента

Используй эти шаблоны, чтобы запросы к coding agent были проверяемыми. Подставляй конкретные значения; не отправляй весь шаблон без заполнения.

## 1. Реализовать требование

```text
Прочитай AGENTS.md и связанные документы SDD.
Реализуй требование [FR-XX]: [краткое описание].
Критерии приёмки:
- [критерий 1]
- [критерий 2]
Ограничения: сохраняй текущий стек и существующий дизайн; не переписывай не связанные компоненты.
Сначала проверь фактическую структуру проекта и предложи план. Затем внеси изменения, запусти релевантные проверки и сообщи изменённые файлы и результаты.
```

## 2. Изучить репозиторий без изменения кода

```text
Прочитай AGENTS.md и документацию проекта. Ничего не меняй.
Опиши фактический стек, точки входа, текущие команды запуска/проверки, реализованные и заглушечные функции, расхождения между кодом и документацией и три ближайших технических шага. Отделяй подтверждённые факты от предположений.
```

## 3. Подключить UI к API

```text
Сначала проверь существующий UI и утверждённый API-контракт. Не меняй визуальный дизайн без необходимости.
Подключи [экран/компонент] к [реальный endpoint, если уже существует]. Учти загрузку, пустой ввод, пустой результат, ошибки, отмену/повтор запроса при необходимости. Не оставляй mock-данные в production-потоке. Если backend/endpoint ещё не существует, не выдумывай его: предложи минимальный согласованный контракт и явно пометь интеграцию как незавершённую.
Добавь проверки и обнови документацию.
```

## 4. Подготовить корпус

```text
Следуй docs/retrieval/corpus-spec.md и docs/retrieval/benchmark.md. Не выдумывай источники или факты о растениях. Для каждой записи сохрани источник и стабильный ID. Проверь дубликаты, пустые поля, формат и корректность URL. Покажи сводку количества записей, ошибок и ограничений выборки. Не называй корпус полным, если это не доказано.
```

## 5. Реализовать/улучшить BM25

```text
Изучи текущий код и спецификацию retrieval. Не меняй контракт результата без обновления интеграционной документации. Реализуй/улучши BM25 для [язык/поля/корпус], затем прогони фиксированный benchmark. Сообщи метод ранжирования, параметры, метрики, примеры успешных и неуспешных запросов и любые ограничения. Не подгоняй benchmark без объяснения.
```

## 6. Проверить реализацию перед PR/сдачей

```text
Проведи ревью относительно AGENTS.md, требований SDD и git diff. Не меняй файлы. Найди ошибки, несоответствия критериям приёмки, регрессии, риски безопасности/секретов, сломанные ссылки, расхождения документации с кодом и отсутствующие тесты. Для каждого замечания укажи серьёзность, файл/строку и конкретный способ исправления. В конце перечисли проверки, которые были возможны, и ограничения ревью.
```
