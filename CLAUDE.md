# Claude Code — проект «Бестиарий растений»

Перед любыми изменениями прочитай корневой `AGENTS.md`, а затем `docs/ai/PROJECT_CONTEXT.md`, `docs/ai/WORKFLOW.md` и `docs/ai/DEFINITION_OF_DONE.md`.

`AGENTS.md` является основной инструкцией проекта и имеет приоритет над этим коротким указателем. Соблюдай существующий стек, сначала исследуй репозиторий, отличай реализованные функции от mock/плана, обновляй SDD при изменении требований или контрактов и запускай только фактически существующие команды проверки. Не выдумывай источники, API, команды запуска и результаты тестов.
